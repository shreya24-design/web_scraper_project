# Automated Web Scraper

## Project Description
This project is an Automated Web Scraper developed using Python. It extracts the latest news headlines from a website and stores them in a structured format for analysis.

## Technologies Used
- Python
- Requests
- BeautifulSoup
- Pandas
- Google Colab

## Features
- Connects to a website
- Extracts news headlines
- Stores data in a DataFrame
- Saves output to a CSV file
- Records scraping date and time
- Generates structured output for analysis

## Output
The project successfully extracts headlines and saves them in a CSV file with date and time information.
